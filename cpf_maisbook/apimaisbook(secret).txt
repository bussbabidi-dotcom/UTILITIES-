# API de Clientes do MaisBook – Consulta pelo Código SGE

Esta API permite consultar a situação de um cliente do MaisBook a partir do seu código SGE. A resposta inclui nome completo, curso, status do álbum e status da seleção de fotos.

> **Observação:** A API é somente leitura. Ela não cria, não altera e não apaga informações no MaisBook.

---

## 1. Visão Geral

| Item                | Valor                                                          |
|---------------------|----------------------------------------------------------------|
| **Método**          | GET                                                            |
| **Endpoint**        | `https://maisbook.com.br/wp-json/maisbook/v1/clientes/{codigo_sge}` |
| **Autenticação**    | Header `X-Maisbook-Api-Key`                                    |
| **Formato resposta**| JSON                                                           |
| **Clientes/chamada**| 1                                                              |


---

## 2. Como Obter a Chave de API

1. Acesse o painel do MaisBook.
2. Vá em **MaisBook → Configurações → API de eventos (agenda)**.
3. Copie a Chave de API (é a mesma da API de eventos).
4. Caso deseje, utilize o botão "Regenerar chave". **Atenção:** a chave antiga para de funcionar imediatamente. Após regenerar, atualize o outro site com a nova chave.

- **Segurança:** Mantenha a chave em segurança, apenas no servidor do site consumidor, como variável de ambiente ou no `wp-config.php`.
- **Nunca coloque a chave em JavaScript** executado no navegador, pois qualquer visitante pode copiá-la e consultar dados pessoais.

---

## 3. Como Fazer a Requisição

- **Endpoint:**  
  Adicione o código SGE do cliente no final da URL:
  ```
  https://maisbook.com.br/wp-json/maisbook/v1/clientes/20431
  ```
  - O código SGE deve conter apenas letras, números, ponto, sublinhado e hífen (vem do campo "Código SGE" do cadastro).

- **Header obrigatório:**  
  ```
  X-Maisbook-Api-Key: SUA_CHAVE_AQUI
  ```

- **Exemplo de chamada com cURL:**
  ```
  curl -sS \
    -H "X-Maisbook-Api-Key: SUA_CHAVE_AQUI" \
    "https://maisbook.com.br/wp-json/maisbook/v1/clientes/20431"
  ```

---

## 4. Resposta de Sucesso (HTTP 200)

Exemplo:
```json
{
  "ok": true,
  "sge": "20431",
  "nome_completo": "Maria da Silva Souza",
  "curso": "Direito",
  "status_album": {
    "codigo": "aprovado",
    "label": "Aprovado",
    "data": "2026-09-20 14:32:10"
  },
  "status_selecao": {
    "codigo": "completo",
    "label": "Completo",
    "data": "2026-09-10 09:15:00"
  }
}
```

### Campos da Resposta

| Campo           | Tipo     | Descrição                                           |
|-----------------|----------|-----------------------------------------------------|
| **ok**          | boolean  | Sempre `true` se a consulta for bem-sucedida        |
| **sge**         | string   | Código SGE consultado                               |
| **nome_completo**| string  | Nome completo do cliente                            |
| **curso**       | string   | Curso do cliente (pode ser vazio)                   |
| **status_album**| objeto   | Situação do álbum ([ver seção 5](#5-status-do-álbum))|
| **status_selecao** | objeto| Situação da seleção ([ver seção 6](#6-status-de-seleção))|

#### Estrutura dos Objetos de Status (`status_album` e `status_selecao`):

| Campo  | Descrição                                                               |
|--------|-------------------------------------------------------------------------|
| codigo | Valor fixo usado para lógica (if/switch)                                |
| label  | Texto pronto para exibição ao usuário                                   |
| data   | Data ligada ao status (formato: AAAA-MM-DD HH:MM:SS) — pode ser vazio  |

---

## 5. Status do Álbum (`status_album`)

Equivale à coluna "Álbum" da listagem de clientes no admin.  

| código           | label                 | O que significa                                       | data               |
|------------------|----------------------|-------------------------------------------------------|--------------------|
| sem_album        | Sem álbum            | Álbum não enviado ao cliente                          | *(vazia)*          |
| pendente         | Pendente             | Álbum cadastrado, mas não liberado ainda              | *(vazia)*          |
| disponivel       | Aguardando Aprovação | Cliente recebeu o álbum, ainda não respondeu          | data do envio      |
| aprovado         | Aprovado             | Cliente aprovou o álbum                               | data da aprovação  |
| com_comentarios  | Com Modificações     | Cliente pediu ajustes                                 | data do pedido     |

---

## 6. Status de Seleção (`status_selecao`)

Equivale ao selo de status na listagem do admin.  
Estados `pendente` e `completo` são recalculados a cada consulta.

| código               | label                 | O que significa                                                                             |
|----------------------|----------------------|---------------------------------------------------------------------------------------------|
| pendente             | Pendente             | Falta selecionar fotos de algum produto do plano                                            |
| completo             | Completo             | Todas as seleções do plano foram concluídas                                                 |
| selecao_finalizado   | Seleção finalizado   | Cliente finalizou a seleção                                                                 |
| finalizado           | Finalizado           | Revisão finalizada pela equipe (etapa final)                                                |
| fotos_tratadas       | Fotos tratadas       | Fotos tratadas já disponíveis nos planos de tratamento                                      |
| aguardando_tratamento| Aguardando tratamento| Cliente já baixou fotos e aguarda tratamento                                                |
| sem_status           | (vazio)              | Plano sem seleção (galeria, link, personalizado ou sem plano)                               |

**Prioridade dos status:**  
1. Finalizado  
2. Seleção finalizado  
3. Completo  
4. Pendente  

---

## 7. Erros

Erros seguem o padrão REST do WordPress. Exemplo:
```json
{
  "code": "maisbook_cliente_not_found",
  "message": "Nenhum cliente encontrado com esse código SGE.",
  "data": { "status": 404 }
}
```

| HTTP | code                      | Quando acontece                                            |
|------|---------------------------|-----------------------------------------------------------|
| 401  | maisbook_api_key_invalid  | Header faltando ou chave incorreta                         |
| 400  | maisbook_cliente_sge_invalid | Código SGE não enviado                                 |
| 404  | maisbook_cliente_not_found  | Cliente com este código SGE não encontrado                |
| 404  | rest_no_route               | URL errada ou código SGE com caracteres inválidos         |

## 8. Exemplos de Integração

#### PHP (WordPress)

No `wp-config.php` do site consumidor:
```php
define('MAISBOOK_API_KEY', 'SUA_CHAVE_AQUI');
```

No código:
```php
function consultar_cliente_maisbook($sge) {
    $response = wp_remote_get(
        'https://maisbook.com.br/wp-json/maisbook/v1/clientes/' . rawurlencode($sge),
        array(
            'headers' => array('X-Maisbook-Api-Key' => MAISBOOK_API_KEY),
            'timeout' => 15,
        )
    );
    if (is_wp_error($response)) {
        return null;
    }
    $code = wp_remote_retrieve_response_code($response);
    $body = json_decode(wp_remote_retrieve_body($response), true);
    if ($code !== 200 || empty($body['ok'])) {
        return null;
    }
    return $body;
}
$cliente = consultar_cliente_maisbook('20431');
if ($cliente) {
    echo esc_html($cliente['nome_completo']);
    echo esc_html($cliente['curso']);
    echo esc_html($cliente['status_album']['label']);
    echo esc_html($cliente['status_selecao']['label']);
    if ($cliente['status_album']['codigo'] === 'aprovado') {
        // ex.: liberar próxima etapa
    }
}
```

#### Node.js (backend)
```js
async function consultarCliente(sge) {
  const res = await fetch(
    `https://maisbook.com.br/wp-json/maisbook/v1/clientes/${encodeURIComponent(sge)}`,
    { headers: { 'X-Maisbook-Api-Key': process.env.MAISBOOK_API_KEY } }
  );
  if (res.status === 404) return null;
  if (!res.ok) throw new Error(`MaisBook respondeu HTTP ${res.status}`);
  return res.json();
}
```

#### Postman / Insomnia

- **Método:** GET
- **URL:** `https://maisbook.com.br/wp-json/maisbook/v1/clientes/20431`
- **Headers:** `X-Maisbook-Api-Key` com o valor da chave

## 9. Funcionamento Interno da API

- O WordPress recebe GET na rota `maisbook/v1/clientes/{sge}`.
- A chave informada no header é conferida por hash (HMAC-SHA256 com salt do WordPress; compara usando hash_equals). Se a chave não bater, retorna 401 e nenhuma consulta é feita.
- O cliente é buscado pelo campo `codigo_interno` (SGE), considerando apenas cadastros publicados.
- Dados retornados:
  - Nome: título do cadastro
  - Curso: meta `curso_cliente`
  - Status do álbum: metas `album_status`, `album_link` e datas de envio/aprovação/comentários
  - Status da seleção: segue regra do selo da listagem do admin, recalculando a cada consulta
- Resposta é sempre em JSON.
- Nenhum dado é gravado no banco durante a consulta.
- O código da API está em `includes/classes/class-api-eventos.php` (método `get_cliente_por_sge`).

---

## 10. Boas Práticas e Limitações

- **Um cliente por chamada.** Não há consulta em lote. Para vários clientes, faça chamadas em sequência, com intervalo entre elas.
- **Evite consultas em excesso.** Caso mostre o status em uma página, faça cache da resposta por alguns minutos (ex: `set_transient` por 5 minutos).
- **Use `codigo` nas lógicas**, `label` apenas na tela. O texto do label pode mudar, o código é estável.
- **Dados pessoais (LGPD):** Nome e curso são dados pessoais. Mostre apenas para quem tem direito (cliente logado ou equipe interna).
- **Troca de chave:** Após regenerar a chave no MaisBook, atualize imediatamente o outro site. Até a atualização, chamadas antigas retornarão 401.
